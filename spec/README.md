# Spec reference

The normative design for this plugin lives here, frozen at the point we
implemented against it. **Where this `spec/` content and `PLANNING.md`
differ, `PLANNING.md` wins** (it records the decisions we made during
implementation — e.g. the ranking contract decision in §6).

| File | What it is |
| --- | --- |
| `Herdr Switcher Spec (standalone).html` | The standalone, bundled spec page (rev 1, 2026-08-21). Self-contained, viewable in a browser. |
| `spec-standalone-src.html` | The source HTML for the standalone spec (readable as plain text). |
| `Herdr Switcher Spec.dc.html` | The spec in the design-tool's native format. |
| `Herdr Switcher.dc.html` | The interactive prototype. Behaviour here is normative where it and the spec agree; the spec wins where they differ. |
| `images/0N-view.png` | The prototype figures referenced by the spec (Figs 1–7). |
| `.thumbnail` | Design-tool thumbnail. |

The spec is rev 1, 2026-08-21. If a newer spec revision arrives, drop it
in here and record the delta in `CHANGELOG.md`.
